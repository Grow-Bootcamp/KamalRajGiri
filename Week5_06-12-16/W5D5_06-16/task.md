# Week 5:Day 2: Relationships, Joins & Datatypes in MySQL

*Description*
Learn how to model and query relationships between tables in MySQL, and understand MySQL's datatype
system.

*Scope*
● Study one-to-one, one-to-many, and many-to-many relationships in MySQL.
● Study SQL joins (inner, left, right, full) and when to use each.
● Study datatypes and numeric data concepts in MySQL.
● Document the day's key learnings, findings, and code snippets in a dedicated learning-log file
(Markdown/Doc) and commit it to the repository.
● Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.
