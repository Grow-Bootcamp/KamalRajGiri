Caching in JS

Caching means storing previously obtained data somewhere so we can reuse it instead of doing the same work/request again.

In JavaScript, caching can be implemented in various ways, such as using variables, objects, or even browser storage mechanisms like localStorage or sessionStorage.

Why Use Caching?

Performance : avoid redundant operations and improve response times.
User Experience : provide faster interactions and smoother navigation.
Resource Efficiency : reduce network requests and server load.

Memoization : Memoization is a caching technique where a function stores results based on its inputs. if calculated earlier with the same inputs, it can return the cached result instead of recalculating. else it will calculate and cache the result.

One limitation of memory caching is that it lives inside running js process and if the process is terminated, the cache is lost. so memory cache is temprorary. This is called volatile/ in-memory caching.

Cache Strategies

  • Cache-aside: application checks cache first
  • Write-through: application updates cache and backend simultaneously
  • Write-back: application updates cache and backend at different times
