Docker

Docker is a platform for developing, shipping, and running applications. It enables developers to package their applications and dependencies into lightweight, portable containers.

Containers are isolated environments that can run on any system with Docker installed, ensuring consistency across different development and production environments.

Container != Virtual Machine

While both containers and virtual machines are used to isolate applications, they differ in their approach and resource utilization. Containers share the host OS kernel, making them more lightweight and efficient, while virtual machines run a full operating system, resulting in higher resource consumption.

The Docker Mental Model

Dockerfile => Image => Container => Running Application

Dockerfile: A text file that contains instructions to build a Docker image.

Image: A read-only template that contains the instructions to create a container.

Container: A running instance of an image.

Running Application: The actual application running inside a container.

Volume: A persistent storage mechanism for containers. container deleted => volume still exists => data is not lost.

Network: A way for containers to communicate with each other and the outside world.

Port: A way to expose a container's internal port to the host system.

Port Mapping: The process of mapping a container's internal port to a port on the host system.

.dockerignore : A file that specifies which files and directories to exclude when building a Docker image.

Note:

Putting everything in one giant container is generally not recommended. It's better to keep each service in its own container for better maintainability and scalability. each container should have a single, clear responsibility.

This idea os closely related to the concept of microservices, although Docker is veryuseful for ordinary monolithic applications.

Docker is not about putting everything in one place. instead , its closer to creating a predictiable, isolated environment for particular application or service.

The Biggest Benifits

Consistency across different environments.
Isolation of applications and dependencies.
Portability across different systems.
Faster deployment and scaling.
Simplified application management and versioning.

Useful Commands

  • docker ps : List running containers
  • docker stop : Stop a running container
  • docker rm : Remove a stopped container
  • docker images : List available images
  • docker rmi : Remove an image
  • docker build -t . : Build an image from a Dockerfile
  • docker run -p : : Run a container from an image and map ports
  • docker logs : View the logs of a container

Docker Compose

allows you to define and run multi-container Docker applications.
