Cross Origin Resourse Sharing

It controls whether a browser allows a webpage from one origin to request resources from another origin via JavaScript.

An origin is basically : a combination of protocol, domain, and port.
for eg: http://example.com:80 is an origin, where http is the protocol, example.com is the domain and 80 is the port.

Typically front and backend are on different origins, so CORS is needed to allow the frontend to communicate with the backend.

when we request from frontend as fetch("http://localhost:5000/api/users"); to the backend , the browser will check if the request is allowed by the CORS policy or not . If the request is not allowed, the browser will block it and the frontend will not be able to communicate with the backend.

CORS is mainly a browser security mechanism. It doesnot mean backend cannot recieve the request , it means the browser will block the request if it is not allowed by the CORS policy. i.e. unless the server explicitly allows the request, the browser will block it.
