Learn foundational database concepts, compare SQL and NoSQL approaches, and get introduced to MongoDB as a NoSQL database.

Scope

Study core database concepts.
Study SQL vs. NoSQL databases and their respective use cases.
Study the concept of ORM (Object-Relational Mapping) at a conceptual level.
Get introduced to MongoDB - installation, structure, and basic usage.

Document the day's key learnings, findings, and code snippets in a dedicated learning-log file (Markdown/Doc) and commit it to the repository.
Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.

Acceptance Criteria

Can explain the key differences between SQL and NoSQL databases with examples of when to use each.
Can explain what an ORM is and why it is used.
Can install MongoDB (or set up MongoDB Atlas) and connect to it successfully.

A daily learning-log file capturing the day's topics and key takeaways is created/updated and committed to the repository.
A GitHub PR is raised for the day's work and sent to the mentor for review.
The learning-log file link and the PR link are both posted in the Zoho task's comment section and in the corresponding Microsoft Teams comment/thread.
