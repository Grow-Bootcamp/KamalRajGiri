3. slice() vs splice()

slice(start, end) returns a selected portion without changing the original array. The end index is excluded.

splice(start, deleteCount, ...items) modifies the original array. It can remove, insert, or replace elements.

Quick Takeaways

  • == allows type conversion; === is strict.
  • || uses a fallback for falsy values.
  • ?? uses a fallback only for null or undefined.
  • slice(start, end) excludes the end index.
  • slice() does not mutate the original array.
  • splice() modifies the original array.
  • For React state, prefer creating a new array instead of mutating existing state.
