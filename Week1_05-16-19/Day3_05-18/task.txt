Day 3: Functions, Objects & Arrays
Description
Understand different ways of defining functions in JavaScript and become comfortable working with
objects and arrays, including their common methods and properties.
Scope 
● Study function expressions, arrow functions, IIFEs, and anonymous functions.
● Study Object methods/properties (Object.keys, Object.values, Object.assign, etc.).
● Study Array methods/properties (map, filter, reduce, push/pop, etc.).
● Practice converting a regular function into an arrow function and an IIFE.
● Document the day's key learnings, findings, and code snippets in a dedicated learning-log file
(Markdown/Doc) and commit it to the repository.
● Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.
Acceptance Criteria
● Can write and explain the difference between function expressions, arrow functions, IIFEs, and
anonymous functions.
● Can manipulate and transform data using at least 5 Object and 5 Array methods.
● Practice code demonstrates correct usage without runtime errors.
● A daily learning-log file capturing the day's topics and key takeaways is created/updated and
committed to the repository.
● A GitHub PR is raised for the day's work and sent to the mentor for review.
● The learning-log file link and the PR link are both posted in the Zoho task's comment section and in the corresponding Microsoft Teams comment/thread.
