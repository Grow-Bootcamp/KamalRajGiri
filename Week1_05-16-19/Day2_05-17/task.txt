Day 2: Control Flow & Strings in JavaScript
Description
Learn how JavaScript controls program flow using conditionals and loops, and gain proficiency in string
manipulation using built-in properties and methods.
Scope
● Study conditional statements (if/else, switch) and their use cases.
● Study loop constructs (for, while, do-while) and different loop functions.
● Study String properties and methods (length, slice, substring, split, replace, trim, etc.).
● Practice writing small scripts using conditionals, loops, and string methods.
● Document the day's key learnings, findings, and code snippets in a dedicated learning-log file
(Markdown/Doc) and commit it to the repository.
● Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.
Acceptance Criteria
● Can choose and correctly implement the appropriate conditional/loop construct for a given
problem.
● Can manipulate strings using at least 6 different built-in string methods.
● Sample practice scripts run without errors and produce expected output.
● A daily learning-log file capturing the day's topics and key takeaways is created/updated and
committed to the repository.
● A GitHub PR is raised for the day's work and sent to the mentor for review.
● The learning-log file link and the PR link are both posted in the Zoho task's comment section and in the corresponding Microsoft Teams comment/thread.
