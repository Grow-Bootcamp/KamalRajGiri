# Week 6:Day 2: User Roles, Permissions & Auth Libraries

*Description*
Learn how to implement role-based access control and explore common libraries/packages used for authentication and authorization.

*Scope*
● Study user roles and permissions design.
● Explore different libraries and packages used for authentication and authorization (e.g., Passport.js, bcrypt, express-jwt, etc.).
● Document the day's key learnings, findings, and code snippets in a dedicated learning-log file (Markdown/Doc) and commit it to the repository.
● Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.

● Can list and describe at least 3 libraries/packages commonly used for authentication/authorization and their use cases.
