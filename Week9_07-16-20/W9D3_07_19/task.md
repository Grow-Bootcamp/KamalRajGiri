# Week 7:Day 5: Forms, Validation & Performance Optimization & Final Presentation

*Description*
Learn advanced form handling techniques in React, including validation and multi-page forms, and apply
performance optimization best practices. Conclude the week by presenting a summary of Days 1-4 to your
mentor.

*Scope*
● Study form handling in React.
● Study validation techniques in React forms.
● Study multi-page form handling.
● Study performance optimization techniques in React (memoization, lazy loading, code splitting).
● Prepare a short presentation covering the key topics learned across Day 1 to Day 4 of this week.
● Present the prepared summary to your mentor and address any questions.
● Document the day's key learnings, findings, and code snippets in a dedicated learning-log file
(Markdown/Doc) and commit it to the repository.
● Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.
● Combine and consolidate all of this week's daily learning-log files (Day 1 through the final day) into
a single weekly learning summary document.

*Acceptance Criteria*
● Can build a form with validation that displays appropriate error messages.
● Can implement a multi-step/multi-page form that retains state across steps.
● Can apply at least one performance optimization technique (e.g., React.memo, lazy loading) to a
component.
● Presentation covering Days 1-4 is prepared and delivered to the mentor.
● A daily learning-log file capturing the day's topics and key takeaways is created/updated and
committed to the repository.
● A GitHub PR is raised for the day's work and sent to the mentor for review.
● The learning-log file link and the PR link are both posted in the Zoho task's comment section and in
the corresponding Microsoft Teams comment/thread.
● A consolidated weekly learning document exists, combining all of this week's daily logs, and is
committed to the repository (via the day's PR or a dedicated PR).
● The weekly learning document link is also shared in the Zoho comment section and the Teams
comment section.
