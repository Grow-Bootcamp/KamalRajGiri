# Week 7:Day 3: State Management with Redux & Redux Toolkit

*Description*
Compare different state management approaches and learn how to implement global state management
using Redux Toolkit.

*Scope*
● Study different state management tools with comparison and use-case scenarios.
● Study Redux and Redux Toolkit and how they work.
● Document the day's key learnings, findings, and code snippets in a dedicated learning-log file
(Markdown/Doc) and commit it to the repository.
● Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.

*Acceptance Criteria*
● Can explain trade-offs between at least 3 state management approaches.
● Can set up a Redux Toolkit store with at least one slice and connect it to a React component.
● A daily learning-log file capturing the day's topics and key takeaways is created/updated and
committed to the repository.
● A GitHub PR is raised for the day's work and sent to the mentor for review.
● The learning-log file link and the PR link are both posted in the Open Project task's comment section and inthe corresponding Microsoft Teams comment/thread.
