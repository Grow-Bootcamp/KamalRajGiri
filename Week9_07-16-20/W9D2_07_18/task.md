# Week 7:Day 4: Context API, Hooks & Chart Libraries

*Description*
Learn alternative state management using Context API and useReducer, deepen knowledge of React Hooks,
and integrate chart libraries for data visualization.

*Scope*
● Study the Context API and useReducer hook.
● Study React Hooks (useState, useEffect, useMemo, useCallback, custom hooks).
● Study chart libraries for React (e.g., Chart.js, Recharts).
● Document the day's key learnings, findings, and code snippets in a dedicated learning-log file
(Markdown/Doc) and commit it to the repository.
● Raise a GitHub Pull Request for the day's practice code/work and send it to your mentor for review.

*Acceptance Criteria*
● Can implement global state using Context API + useReducer as an alternative to Redux.
● Can use at least 3 different React Hooks correctly in a sample component.
● Can render a chart (e.g., bar/line chart) using a chart library with sample data.
● A daily learning-log file capturing the day's topics and key takeaways is created/updated and
committed to the repository.
● A GitHub PR is raised for the day's work and sent to the mentor for review.
The learning-log file link and the PR link are both posted in the OpenProject task's comment section and in
the corresponding Microsoft Teams comment/thread.
